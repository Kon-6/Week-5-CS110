CS110 • COURSE RECAP

Weeks 1–4

My CS110 Course Recap and Learning Reflection

Week 1 — Mindset & Web Basics

Week 1 taught me about having the right mindset when learning something new. I also learned the basic parts of a website.

  • HTML gives a website its structure.
  • CSS controls how the website looks.
  • JavaScript allows the user to interact with the website.
  • AI can be used as a tool to help us learn and build.

Week 2 — Expanding My Knowledge

Week 2 helped me expand my knowledge of web development. I learned more about the tools and frameworks developers can use when creating projects.

  • Learned more about web development tools.
  • Learned about frameworks.
  • Used AI to help build and understand projects.

Week 3 — Storytelling

Week 3 focused on storytelling and how we can make a website more interesting for the user.

  • Learned about storytelling frameworks.
  • Used the AAA framework.
  • AAA stands for Attention, Action, and Amplification.
  • Learned how a website can guide the user's experience.

Week 4 — Enhanced Storytelling & 3D

Week 4 expanded on storytelling and introduced 3D elements that can be added to websites.

  • Worked with enhanced storytelling.
  • Implemented 3D elements into a website.
  • Learned how other tools can be incorporated into a project.
  • Worked with 3D images and frameworks.

Reusable npm Packages

An npm package is reusable code that developers can add to their projects instead of creating everything from scratch.
